// WEB LAB

实验室

能塞进浏览器的，就不放到服务器上。数据不出本机是这里的默认设定， 除了明确标注"经边缘代理"的侦察功能，其余计算全部在你自己的 CPU / GPU 上跑。

BAY-01可用

模型舱

在画布上点出自己的数据集，现场训练一个多层感知机：反向传播、决策边界与损失曲线全都实时可见。

  • WebGPU 可选
  • 手写反向传播
  • 零上传
BAY-02可用

安全舱

JWT 解析与验签、WebCrypto 哈希与派生、编码互转，外加经边缘代理的 DNS / 证书 / 响应头侦察。

  • WebCrypto
  • HIBP k-匿名
  • DoH / CT
BAY-03可用

设备舱

WebUSB 直连安卓机：工具模式能开交互终端、管理应用、装 APK、改分辨率密度、模拟按键与电池、传文件；协议模式自己讲 ADB 握手。

  • WebUSB
  • ya-webadb
  • 手写 ADB
BAY-04可用

数据舱

拖入 Chrome 的 .heapsnapshot，在 Worker 里本地解析：按类型聚合自占用、Top 节点、detached 计数与重复长字符串。

  • Web Worker
  • 零上传
  • v1.0
BAY-06可用

小品舱

从旧作品迁过来的小游戏、视觉玩具与速查资料：排行榜和投票接的是本站 KV，页面本身一行业务代码没改。

  • 13 个页面
  • KV 排行
  • 纯前端
BAY-05可用

连接舱

WebRTC 点对点传文件，信令靠手动复制粘贴，文件不经过服务器；带一个本机回环自检。

  • WebRTC
  • DataChannel
  • 零中转
