// SKILL RACK

技能包

写 agent 的 skill 和写 shell 别名一样，攒着攒着就散了。skkill 把它们收进 ~/.skkill/skills，再用软链接分发到你常用的每个 agent——一处升级，处处生效。

INSTALL 
$ npm i -g @steven-y/skkill
  1. 01

    装一个技能

    skkill install owner/repo -a claudecode

    支持 owner/repo 简写与任意 git URL，自动识别仓库里的 SKILL.md。

  2. 02

    链到所有 agent

    skkill link all

    目标包括 claudecode、codex、comate、opencode、dsh，也可以单独指定。

  3. 03

    自己写一个

    skkill init my-skill -d "一句话用途"

    生成骨架后交给 coding agent 填内容，再用 skkill validate 做本地校验。

// 仓库

两个可以直接用的项目

skkillCLI

跨 agent 的 skill 包管理器：安装、校验、迁移、分发一条龙，用 package.json 当版本控制。

TypeScript · MIT · npm ↗
fanzha-skillSKILL

反诈技能包：把常见骗术的识别线索、追问话术和判断流程整理成 agent 能直接套用的知识。

Skill · MIT · GitHub ↗

技能内容与 agent 环境强相关，装之前建议先看一眼仓库里的 SKILL.md，别把不认识的命令直接跑起来。
